# Subtitles / Субтитры

[English](#english) · [Русский](#русский)

## English

SRT subtitles for a video course.

### Files

- `lessonN.srt` — original English subtitles (in lessons 3 and 4 the speech-recognition errors are fixed and long cues are split).
- `lessonN.ru.srt` — Russian translation with the same timestamps (long cues are split).

### What is translated

| Lesson | Translated | Why |
|--------|------------|-----|
| 1 | no | too basic |
| 2 | no | just an introduction, not worth watching |
| 3 | yes (`lesson3.ru.srt`) | |
| 4 | yes (`lesson4.ru.srt`) | |

## Русский

SRT-субтитры видеокурса.

### Файлы

- `lessonN.srt` — оригинальные английские субтитры (в уроках 3 и 4 исправлены ошибки автораспознавания речи и разбиты длинные реплики).
- `lessonN.ru.srt` — русский перевод с теми же тайм-кодами (длинные реплики разбиты).

### Что переведено

| Урок | Перевод | Почему |

| 1 | нет | слишком простой |
| 2 | нет | только знакомство, смотреть не обязательно |
| 3 | да (`lesson3.ru.srt`) | |
| 4 | да (`lesson4.ru.srt`) | |
